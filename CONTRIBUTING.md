# Contributing

## Setup

```bash
npm install
npx playwright install chromium   # once, for the e2e suite
npm run dev                       # http://localhost:5173
```

On first run the app shows the gate screen. Click **Create new file…** and save
`task-tracker-task.json` in your home folder; that file is now your database.

## Workflow

1. Read [CLAUDE.md](CLAUDE.md) for the rules that must not be broken.
2. Work outside-in: data model (`src/types.ts`, `src/schema.ts`) → pure logic
   (`src/mutations.ts` and friends) → hook (`src/store.ts`) → components.
3. Write the unit test with, or before, the logic. Pure modules are cheap to
   test and that is the point of their being pure.
4. Add a Playwright spec for anything a user can see or click.
5. Run `npm run typecheck && npm run lint && npm run test:all` before calling
   it done.

## Definition of done

- [ ] Typecheck and lint clean.
- [ ] Unit tests cover the new logic; the coverage gate still passes.
- [ ] A Playwright spec covers the new user-visible behaviour.
- [ ] The task file still loads if the new field is missing (hand-edited files).
- [ ] Keyboard and screen-reader paths work (see UI-CONVENTIONS.md).
- [ ] Docs updated: `DATA-MODEL.md` for schema changes, `ARCHITECTURE.md` for
      structural ones, `TESTING.md` for new seams or suites.

## Commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Dev server; the only build with the `?e2e=` test seam |
| `npm run build` | Typecheck + production build with the service worker |
| `npm run preview` | Serve the production build (what gets installed) |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | oxlint |
| `npm run test` / `test:watch` / `test:coverage` | Vitest |
| `npm run test:e2e` | Playwright; starts both servers itself |
| `npm run test:all` | Coverage gate + Playwright |

## Icons

`public/icon-*.png` and `favicon.svg` are a 2×2 Covey grid. The PNGs were
generated by a dependency-free Python script that writes raw PNG chunks; if the
palette changes, regenerate them with the same cell colours as `--q1`…`--q4` in
`src/styles.css`, keeping the maskable icon's content inside the safe zone
(~24% inset).

## Gotchas

- `verbatimModuleSyntax` is on: use `import type` for type-only imports, and
  `.ts`/`.tsx` extensions on relative imports.
- `erasableSyntaxOnly` is on: no enums and no constructor parameter properties.
- The dev build is where E2E runs, because the test seam is dev-only. If you
  change `main.tsx`'s store selection, re-run `pwa.spec.ts`.
- React runs effects twice in development. Anything that captures "what was
  focused before" must do so during render, not in an effect — see `Modal.tsx`.
